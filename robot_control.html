Bước 1 — Kết nối BLE
Mở phiên Web Bluetooth với robot để nhận trạng thái provisioning và gửi các lệnh SSID/PASS/SCAN.

chrome|edge required :: origin=https:// or http://localhost

Bước 2 — Quét mạng WiFi
Gửi trigger `SCAN` qua BLE. Danh sách mạng sẽ stream ngược lại qua characteristic trạng thái.
Bước 3 — Kết nối WiFi
Gửi SSID và password sang firmware. Khi ESP32 vào mạng thành công, UI sẽ chuyển sang chế độ HTTP runtime.
